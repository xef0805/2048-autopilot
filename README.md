# 2048 自动冲分

一个可以自己玩 2048 的中文网页小游戏，支持自动挑战高分，也可以手动操作。

## 运行

下载并解压项目，用浏览器打开 `index.html` 即可，无需安装依赖。

## 操作

- **新开一局**：重新开始。
- **自动走一步**：让程序走一步，观察它的选择。
- **连续自动玩 / 暂停**：开始或暂停自动运行。
- **方向键、WASD 或滑动棋盘**：手动玩，同时暂停自动玩家。

程序会根据棋盘情况预判 2～4 次移动，达到 2048 后继续挑战。棋盘拥挤时思考较久，暂停需要等待当前步计算完成。
